# hoppii課題自動通知システム

大学のLMS「hoppii(WebClass)」の課題提出期限を、自動でSlackに通知する仕組みです。

## 背景・目的

大学の課題提出期限を見落としてしまうことがあり、確認作業自体も面倒だったため、
「課題の締切を自動で拾ってきて、通知してくれる仕組み」を作ろうと考えました。
ノーコード自動化ツール(Make)とJavaScriptを組み合わせて実現しています。

## できること

- hoppii(WebClass)上の全授業ページを自動で巡回し、課題情報を収集
- 提出不要な「資料」カテゴリを除外し、未来の締切だけを抽出
- Google Calendarへの自動登録、Slackへの自動通知
- 一度通知した課題は再通知しない(重複防止)

## 全体の仕組み

1. ブラウザで本人がログインし、JSコードを実行
2. 全授業ページを自動巡回し、課題データを抽出
3. 「資料」カテゴリを除外、未来の締切だけにフィルタ
4. 課題ごとに一意のIDを生成
5. Make(Webhook)で受信し、重複チェック(送信済みならスキップ)
6. 新規の場合のみGoogle Calendarに登録
7. Makeが1日1回、新しいカレンダーイベントを検知
8. Slackに自動通知

## 技術的に工夫した点

### 1. 多段階認証の壁を、設計変更で乗り越えた

当初は完全自動ログインを目指していましたが、大学のLMSが多段階のJSON認証方式を
採用しており、標準的な自動化ツールだけでは実装が困難でした。
規約上のリスクも考慮した上で、認証部分は本人の手動ログインに任せ、
ログイン後のセッションを使ってデータ収集だけを自動化する「半自動方式」に設計を転換しました。

### 2. LMS内部の2段階リダイレクト認証を解析

各授業ページへのアクセスは、単純なリンクではなく、
1回目のアクセスでは新しいトークン付きURLへのリダイレクトが返るだけで、
それを検出して2回目のアクセスをして初めてページの中身が取得できる、
という仕組みになっていました。この構造をHTMLレスポンスを解析することで突き止め、
2段階のfetch処理として実装しています。

### 3. 重複防止の仕組み

課題ごとに「授業名+課題名+締切」から一意のIDを生成し、
Make側のデータストアで送信済みかどうかをチェックすることで、
同じ課題を何度実行しても重複通知されないようにしています。

## 使用技術

- JavaScript(Fetch API、DOM解析)
- Make(ノーコード自動化ツール、Webhook・データストア・Google Calendar連携)
- Slack(通知先)

## 使い方

1. hoppiiにログインした状態で時間割ページを開く
2. ブラウザのDevTools(Console)を開く
3. hoppii_scraper(7).js の中身をコピーして貼り付け、Enter
5. 自動で課題データが収集され、Makeへ送信される

※ WEBHOOK_URL は各自のMake Webhook URLに置き換えて使用してください。
